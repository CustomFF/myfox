# MyFox

MyFox – инструментарий для установки и сопровождения официального Firefox с
[MyFox tweaks](https://github.com/CustomFF/myfox-tweaks).

## Требования

- Linux, x86_64 или aarch64: Python 3.8 или новее, curl
- Windows 10 или 11, x64 или ARM64: ничего (MyFox приносит свой Python)

## Установка

Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/CustomFF/myfox/master/get.sh | sh
```

Windows, в PowerShell (не от администратора):

```powershell
irm https://raw.githubusercontent.com/CustomFF/myfox/master/get.ps1 | iex
```

Режимы установки:

- интерактивно, TUI-диалог (по умолчанию);
- интерактивно, GUI-диалог – `sh -s -- --gui`;
- без вопросов, настройки по умолчанию – `sh -s -- -y`.

Установка управляется флагами, они передаются после `sh -s --`; в Windows –
`& ([scriptblock]::Create((irm https://raw.githubusercontent.com/CustomFF/myfox/master/get.ps1))) --gui`.
Все флаги описаны в [документации](https://github.com/CustomFF/myfox/wiki).

Firefox устанавливается в домашний каталог (по умолчанию ~/.local/share/myfox/firefox) с отдельным
профилем: новым или копией профиля другого Firefox (в том числе snap и flatpak). Аккаунт Firefox
можно оставить в исходном профиле, войти в обоих или перенести в копию. Права root не нужны,
установленный в системе Firefox не затрагивается, его профили только читаются.

После установки в меню приложений появляется ярлык Firefox, в ~/.local/bin – команда `myfox`
(каталог должен быть в PATH).

В Windows всё ставится в %LOCALAPPDATA%\myfox, только для вашего пользователя, без прав
администратора: Firefox (из установщика Mozilla), embeddable-Python с python.org, на котором работает
MyFox, и сам MyFox. В меню «Пуск» появляется папка MyFox (Firefox, «Приватный просмотр
Firefox», «Обновить MyFox»), в «Параметры → Приложения» – MyFox (там же удаление), а команда `myfox` работает в новом окне терминала.
Графическим диалогам нужен x64; на ARM64 диалоги открываются в консоли.

## Обновление

Firefox обновляется сам, встроенным механизмом Mozilla, а не через пакетный менеджер
дистрибутива. Твики, темы и MyFox обновляются командой `myfox refresh` или пунктом
«Обновить MyFox» в контекстном меню ярлыка (в Windows – в папке MyFox меню «Пуск»).

Обновлённые твики применяются после перезапуска Firefox. `myfox refresh` предлагает перезапуск,
пункт «Перезапустить» есть в меню ярлыка (Linux) и на странице `about:myfox` из твиков; окна и
вкладки при перезапуске восстанавливаются.

Твики делаются под текущую бету Firefox и проверяются на стабильной версии перед ней. Если ваш
Firefox старее и последние твики на нём работают плохо, можно вернуться к сделанным под него:

```text
myfox tweaks                     установленная версия твиков и версия Firefox
myfox tweaks versions            версии твиков, по одной на версию Firefox
myfox tweaks use 159             поставить твики для Firefox 159 и закрепить их
myfox tweaks use latest          вернуться к последним; refresh снова их обновляет
```

## Профили

```text
myfox profile list               профили MyFox и те, что он может взять
myfox profile new                новый профиль с твиками
myfox profile import <ID>        скопировать (или --move) профиль другого Firefox в новый
myfox profile use <ID>           какой профиль открывает этот Firefox
myfox profile rename <ID> <ИМЯ>
myfox profile remove <ID>
```

Создание, импорт, переименование и удаление профилей работают при открытом Firefox; несколько
профилей MyFox можно держать открытыми одновременно, каждый в своём окне. Только смена профиля по
умолчанию требует закрыть Firefox: MyFox закрывает и снова открывает его, сеанс сохраняется. То же
есть на странице `about:myfox` из твиков. Подробнее – в
[документации](https://github.com/CustomFF/myfox/wiki/Профили).

## Другие команды

```text
myfox reinstall     повторно скачать Firefox; профиль не меняется
myfox command on    запускать этот Firefox командой firefox (в Windows – и через Win+R)
myfox completion    скрипт автодополнения (для bash и fish ставится при установке)
myfox help          список всех команд
```

## Удаление

```bash
myfox uninstall
```

Или, в Windows, «Параметры → Приложения → MyFox → Удалить».

Удаляются Firefox, ярлык, команда `myfox` и каталог MyFox. Профиль (закладки, история,
пароли) сохраняется; чтобы удалить и его, отметьте «Удалить и профиль» в диалоге (удаляются только
профили, созданные MyFox). Если при установке аккаунт Firefox был перенесён в копию, он
возвращается в исходный профиль.

## about:myfox и безопасность

Страница `about:myfox` из твиков запускает команду `myfox` для своих кнопок (обновления, профили,
команда firefox). Это страница самого браузера: сайты не могут её открыть, встроить или дотянуться до
неё, а кнопки срабатывают только по нажатию. Она запускает только то, что MyFox записал в `myfox.json`
установки, и передаёт аргументы программе как есть, никогда через оболочку (в Windows – `pythonw`, а
не bat-файл, чей `cmd.exe` принял бы кавычку и `&` в имени профиля за команды). Подменить эти файлы
можно, только имея запись в ваш домашний каталог, а это уже позволяет что угодно от вашего имени;
от такого MyFox не защищает и не обещает защищать.

## Политика подписи кода (Code signing policy)

Бесплатная подпись кода предоставлена [SignPath.io](https://about.signpath.io), сертификат выдан
[SignPath Foundation](https://signpath.org).

Подписывается только `MyFox-Setup.exe`. Его собирает GitHub Actions из этого репозитория, а каждый
релиз перед подписью одобряется вручную.

Авторы, рецензенты и утверждающие: [DayDve](https://github.com/DayDve).

Приватность: MyFox не отправляет телеметрию. Он обращается только к GitHub, python.org и Mozilla,
чтобы скачать то, что устанавливает, и проверить обновления.

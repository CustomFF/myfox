# MyFox

MyFox — инструментарий для установки и сопровождения официального Firefox с
[MyFox tweaks](https://github.com/CustomFF/myfox-tweaks).

## Требования

- Linux, x86_64 или aarch64
- Python 3.8 или новее
- curl

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/CustomFF/myfox/master/get.sh | sh
```

Режимы установки:

- интерактивно, TUI-диалог (по умолчанию);
- интерактивно, GUI-диалог — `sh -s -- --gui`;
- без вопросов, настройки по умолчанию — `sh -s -- -y`.

Установка управляется флагами, они передаются после `sh -s --`. Все флаги описаны в
[документации](https://github.com/CustomFF/myfox/wiki).

Firefox устанавливается в домашний каталог (по умолчанию ~/.local/share/myfox/firefox) с отдельным
профилем: новым или копией профиля другого Firefox (в том числе snap и flatpak). Аккаунт Firefox
можно оставить в исходном профиле, войти в обоих или перенести в копию. Права root не нужны,
установленный в системе Firefox не затрагивается, его профили только читаются.

После установки в меню приложений появляется ярлык Firefox, в ~/.local/bin — команда `myfox`
(каталог должен быть в PATH).

## Обновление

Firefox обновляется сам, встроенным механизмом Mozilla, а не через пакетный менеджер
дистрибутива. Твики, темы и MyFox обновляются командой `myfox refresh` или пунктом
«Обновить MyFox» в контекстном меню ярлыка.

Обновлённые твики применяются после перезапуска Firefox. `myfox refresh` предлагает перезапуск,
в меню ярлыка есть пункт «Перезапустить»; окна и вкладки при перезапуске восстанавливаются.

## Профили

```text
myfox profile list               профили MyFox и те, что он может взять
myfox profile new                новый профиль с твиками
myfox profile import <ID>        скопировать (или --move) профиль другого Firefox в новый
myfox profile use <ID>           какой профиль открывает этот Firefox
myfox profile rename <ID> <ИМЯ>
myfox profile remove <ID>
```

Создание, импорт, переименование и удаление профилей работают при открытом Firefox; несколько
профилей MyFox можно держать открытыми одновременно, каждый в своём окне. Только смена профиля по
умолчанию требует закрыть Firefox: MyFox закрывает и снова открывает его, сеанс сохраняется. То же
есть на странице `about:myfox` из твиков. Подробнее — в
[документации](https://github.com/CustomFF/myfox/wiki/Профили).

## Другие команды

```text
myfox reinstall     повторно скачать Firefox; профиль не меняется
myfox command on    запускать этот Firefox командой оболочки firefox
myfox completion    скрипт автодополнения (для bash и fish ставится при установке)
myfox help          список всех команд
```

## Удаление

```bash
myfox uninstall
```

Удаляются Firefox, ярлык, команда `myfox` и ~/.local/share/myfox. Профиль (закладки, история,
пароли) сохраняется; чтобы удалить и его, отметьте «Удалить и профиль» в диалоге (удаляются только
профили, созданные MyFox). Если при установке аккаунт Firefox был перенесён в копию, он
возвращается в исходный профиль.
